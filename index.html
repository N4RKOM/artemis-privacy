Как мобильное приложение Artemis обрабатывает данные при работе с учебным порталом.

1. Кто отвечает за приложение

Разработчик и издатель Artemis — N4R. По вопросам конфиденциальности: n4r.artemis@gmail.com.

2. Какие данные обрабатываются

  • Данные для входа: логин и пароль, введённые пользователем.
  • Данные профиля и учебные данные: идентификатор и имя пользователя, расписание, оценки, задания, экзамены, посещаемость, учебные материалы, объявления, сообщения и другие сведения, доступные учётной записи на портале.
  • Данные сессии: токены, cookies и другие идентификаторы, необходимые для поддержания входа.
  • Записи пользователя: заметки к предметам, которые хранятся только на устройстве, а также ответы на анкеты и заявления, которые пользователь сам отправляет на портал.
  • Локальные настройки: язык, тема, параметры уведомлений и фоновой проверки, подтверждение согласия, ПИН-код в виде криптографического проверочного значения и выбранные пользователем настройки защиты.
  • Файлы: материалы, которые пользователь самостоятельно загружает или открывает из учебного портала.

3. Как и зачем используются данные

Данные используются только для авторизации в учебном портале, загрузки и показа доступной пользователю учебной информации, офлайн-работы, напоминаний, фоновой проверки новых уведомлений и оценок, защиты доступа к приложению и выполнения действий, явно выбранных пользователем.

Фоновая проверка портала включена по умолчанию. По расписанию — в 9, 12, 15, 18 и 21 час по времени устройства, ночных запусков в расписании нет — Artemis сам обращается к порталу и проверяет, появились ли новые уведомления и новые оценки в журнале текущего семестра. Android может сдвинуть запуск позже, например при экономии заряда; проверка выполняется только при подключении к сети. Если сессия истекла, а пользователь сохранил пароль, Artemis входит на портал заново с этим паролем; без сохранённого пароля после истечения сессии проверка не проходит, пока пользователь снова не войдёт. О найденном Artemis сообщает локальным уведомлением. Проверку можно отключить целиком или отдельно для уведомлений и для оценок в настройках уведомлений.

Логин и пароль передаются по HTTPS непосредственно поддерживаемому учебному порталу на домене edu.aues.kz. У N4R нет собственного сервера, который получает логин, пароль, токены или учебные данные.

4. Хранение на устройстве

Токены сессии и добровольно сохранённый пароль хранятся в защищённом системном хранилище Android. Пароль сохраняется только после отдельного выбора пользователя на экране входа. Часть учебных данных хранится локально для офлайн-доступа. Для фоновой проверки оценок Artemis хранит последний полученный снимок журнала текущего семестра и сравнивает с ним новый. Заметки к предметам хранятся только на этом устройстве и никуда не передаются. Биометрические шаблоны приложению не передаются — проверку выполняет Android.

5. Разрешения

  • Камера используется для сканирования QR-кода посещаемости. Кадры обрабатываются на устройстве и не сохраняются Artemis.
  • Уведомления используются для локальных напоминаний и для сообщений фоновой проверки о новых уведомлениях портала и новых оценках. Если включён ПИН-код, текст уведомлений портала и баллы в уведомлениях не показываются — только предложение открыть Artemis.
  • Биометрия используется только для подтверждения личности средствами Android, если пользователь включил эту возможность.

6. Передача третьим сторонам

Необходимые данные передаются оператору учебного портала для выполнения запрошенных функций. Ответы на анкеты передаются порталу; если портал отмечает анкету как неанонимную, Artemis предупреждает об этом до начала заполнения. Artemis не продаёт данные, не показывает рекламу и не использует собственную аналитику или удалённый сбор сбоев. При открытии или отправке файла выбранное внешнее приложение обрабатывает его по собственным правилам.

Для распознавания QR-кодов Artemis использует встроенный Google ML Kit. Изображения с камеры и распознанное содержимое QR-кодов обрабатываются на устройстве и не отправляются Google. При этом ML Kit может передавать Google сведения об устройстве и приложении, не предназначенный для идентификации пользователя идентификатор установки, а также метрики производительности и использования — для диагностики, аналитики, обслуживания и предотвращения злоупотреблений. Google сообщает, что эти данные передаются по HTTPS и не передаются третьим лицам. Подробнее — в описании обработки данных ML Kit.

Эта страница размещена на GitHub Pages. GitHub может обрабатывать технические данные посещения, включая IP-адрес, в соответствии со своей политикой конфиденциальности.

7. Срок хранения и удаление

Данные хранятся на устройстве, пока пользователь не выйдет из профиля. При выходе Artemis удаляет все свои локальные данные: токены, cookies и сохранённый пароль, ПИН-код, учебный кэш вместе со снимком журнала для проверки оценок, внутреннюю базу, заметки к предметам, настройки и подтверждение согласия, данные виджетов, запланированные напоминания, показанные уведомления портала и файлы, загруженные через Artemis. То же происходит, если пользователь отказывается от согласия на экране настройки.

Копии файлов, которые пользователь сам открыл или отправил в другом приложении, остаются в нём по его правилам. Удалить все локальные данные Artemis также можно средствами Android или удалив приложение. Данные на учебном портале хранятся и удаляются его оператором; N4R не имеет доступа для их удаления.

8. Безопасность, согласие и изменения

Сетевые запросы выполняются только по HTTPS; незашифрованный HTTP в Android запрещён. Чувствительные данные помещаются в защищённое системное хранилище, а доступ к приложению можно дополнительно закрыть ПИН-кодом и биометрией.

ПИН-код и биометрия закрывают вход в приложение и скрывают текст уведомлений, но не шифруют учебный кэш на устройстве и не скрывают виджеты рабочего стола. Если пользователь добавил виджет, его содержимое — ближайшее событие, пары на сегодня, сроки заданий, GPA и оценки недели — видно на рабочем столе без разблокировки Artemis.

Пользователь подтверждает согласие в приложении. Отказаться можно на экране согласия, а позже — выйдя из профиля или очистив данные приложения средствами Android; в каждом случае локальные данные Artemis удаляются. Существенные изменения политики получают новую версию и требуют повторного согласия. Вопросы и запросы можно направить на n4r.artemis@gmail.com.

3. Мақсаты және жіберілуі

Деректер порталға кіру, оқу ақпаратын көрсету, офлайн жұмыс, еске салғыштар, жаңа хабарламалар мен бағаларды фондық тексеру және қолданбаны қорғау үшін ғана пайдаланылады.

Фондық тексеру әдепкі бойынша қосулы. Кесте бойынша — құрылғы уақытымен сағат 9, 12, 15, 18 және 21-де, кестеде түнгі іске қосу жоқ — Artemis порталға өзі жүгініп, жаңа хабарламалар мен ағымдағы семестр журналында жаңа бағалар пайда болғанын тексереді. Android іске қосуды кейінге жылжытуы мүмкін, мысалы, батареяны үнемдеу кезінде; тексеру тек желі болғанда орындалады. Сессия аяқталса және пайдаланушы құпиясөзді сақтаған болса, Artemis сол құпиясөзбен порталға қайта кіреді; құпиясөз сақталмаса, сессия аяқталғаннан кейін пайдаланушы қайта кіргенге дейін тексеру өтпейді. Табылғаны туралы Artemis жергілікті хабарлама көрсетеді. Тексеруді толығымен немесе хабарламалар мен бағалар үшін бөлек хабарламалар баптауларында өшіруге болады.

Логин мен құпиясөз HTTPS арқылы тікелей edu.aues.kz доменіндегі оқу порталына жіберіледі. N4R-дың бұл деректерді қабылдайтын жеке сервері жоқ.

Бағаларды фондық тексеру үшін Artemis ағымдағы семестр журналының соңғы алынған көшірмесін сақтап, жаңасын онымен салыстырады. Пәнге жазбалар тек осы құрылғыда сақталады және ешқайда жіберілмейді. 6. Үшінші тараптар

Artemis деректерді сатпайды, жарнама көрсетпейді және жеке аналитика немесе қашықтан ақау жинау сервистерін қолданбайды. Сыртқы қолданбада ашылған не жіберілген файл сол қолданбаның ережелерімен өңделеді.

QR-кодтарды тану үшін Artemis құрылғыға ендірілген Google ML Kit-ті қолданады. Камера кескіндері мен QR-кодтың танылған мазмұны құрылғыда өңделеді және Google-ға жіберілмейді. ML Kit диагностика, аналитика, қызмет көрсету және теріс пайдалануды анықтау үшін құрылғы мен қолданба туралы ақпаратты, пайдаланушыны анықтауға арналмаған орнату идентификаторын, сондай-ақ өнімділік пен пайдалану көрсеткіштерін Google-ға жібере алады. Google бұл деректер HTTPS арқылы шифрланып, үшінші тараптарға берілмейтінін хабарлайды. Толығырақ ML Kit деректерін ашу нұсқаулығында.

Бұл бет GitHub Pages-та орналасқан. GitHub өзінің құпиялылық саясатына сай IP-мекенжай сияқты техникалық кіру деректерін өңдеуі мүмкін.

Деректер пайдаланушы профильден шыққанға дейін құрылғыда сақталады. Пайдаланушы баптау экранында келісімнен бас тартса да, дәл осылай болады.

Пайдаланушы басқа қолданбада өзі ашқан не жіберген файлдардың көшірмелері сол қолданбада оның ережелерімен қалады. Порталдағы деректерді оның операторы басқарады.

8. Қауіпсіздік және келісім

Желі байланысы HTTPS арқылы орындалады, ал сезімтал деректер қорғалған жүйелік қоймада сақталады.

ПИН-код пен биометрия қолданбаға кіруді жабады және хабарламалар мәтінін жасырады, бірақ құрылғыдағы оқу кэшін шифрламайды және жұмыс үстеліндегі виджеттерді жасырмайды. Пайдаланушы виджет қосса, ондағы мәлімет — жақын оқиға, бүгінгі сабақтар, тапсырма мерзімдері, GPA және апта бағалары — Artemis-ті ашпай-ақ жұмыс үстелінде көрінеді.

Пайдаланушы қолданбада келісім береді. Одан келісім экранында, ал кейін профильден шығу немесе Android құралдарымен қолданба деректерін тазалау арқылы бас тартуға болады; әр жағдайда Artemis-тің жергілікті деректері жойылады. Елеулі өзгерістер жаңа нұсқамен белгіленіп, қайта келісуді талап етеді.

English version

1. Who is responsible for the app

Artemis is developed and published by N4R. Privacy contact: n4r.artemis@gmail.com.

2. Data processed

  • The username and password entered by the user.
  • Profile ID and name, schedule, grades, assignments, exams, attendance, learning materials, announcements, messages, and other data available to the portal account.
  • User entries: subject notes, which stay on the device, and survey answers and requests that the user submits to the portal.
  • Session tokens, cookies, local preferences (including notification and background-check settings), consent records, a cryptographic PIN verifier, and files downloaded by the user.

3. Purpose and transmission

Data is used only to sign in to the education portal, display academic information, provide offline access and reminders, check for new notifications and marks in the background, secure the app, and carry out actions chosen by the user.

The background check is on by default. It is scheduled for 9, 12, 15, 18 and 21 o'clock device time, with no runs scheduled at night: Artemis contacts the portal on its own and checks for new notifications and new marks in the current term's gradebook. Android may postpone a run, for example to save battery, and a check only runs with a network connection. If the session has expired and the user saved the password, Artemis signs in to the portal again with it; without a saved password, checks fail after the session expires until the user signs in again. Findings are shown as local notifications. The check can be turned off entirely, or separately for notifications and marks, in notification settings.

The username and password are sent over HTTPS directly to the supported education portal at edu.aues.kz. N4R has no server that receives credentials, tokens, or academic data.

4. On-device storage

Session tokens and, only when separately selected by the user, the password are stored in Android protected storage. Some academic data is cached locally for offline access. For the background mark check, Artemis keeps the last received copy of the current term's gradebook and compares new data with it. Subject notes are kept on this device only and are never transmitted. Biometric templates are never provided to Artemis; authentication is performed by Android.

5. Permissions

  • The camera scans attendance QR codes on the device; Artemis does not retain camera frames.
  • Notifications provide local reminders and report new portal notifications and new marks found by the background check. When a PIN is set, portal notification text and scores are hidden and the notification only asks to open Artemis.
  • Biometrics only confirms identity through Android when enabled by the user.

6. Third parties

Required data is transferred to the education portal operator to provide requested functions. Survey answers are sent to the portal; if the portal marks a survey as not anonymous, Artemis warns the user before it is filled in. Artemis does not sell data, display advertising, or operate its own analytics or remote crash-reporting services. A file opened or shared with another app is processed under that app's terms.

Artemis uses bundled Google ML Kit to recognize QR codes. Camera images and recognized QR-code contents are processed on the device and are not sent to Google. ML Kit may send Google device and app information, a per-installation identifier not intended to identify the user, and performance and utilization metrics for diagnostics, analytics, maintenance, and abuse detection. Google states that this data is encrypted in transit using HTTPS and is not shared with third parties. See the ML Kit data disclosure guide.

7. Retention and deletion

Data stays on the device until the user signs out. Signing out deletes all of Artemis's local data: tokens, cookies and the saved password, the PIN, the academic cache together with the gradebook copy used for mark checks, the internal database, subject notes, settings and consent, widget data, scheduled reminders, portal notifications already shown, and files downloaded through Artemis. The same happens if the user declines consent on the setup screen.

Copies of files the user opened or shared in another app stay there under that app's terms. Data held by the education portal is controlled by its operator.

8. Security and consent

Network requests use HTTPS and sensitive values are placed in protected system storage.

The PIN and biometrics lock access to the app and hide notification text, but they do not encrypt the academic cache on the device or hide home-screen widgets. If the user adds a widget, its contents — the next event, today's classes, assignment deadlines, GPA, and weekly marks — are visible on the home screen without unlocking Artemis.

The user provides consent in the app. It can be declined on the consent screen and withdrawn later by signing out or by clearing app data in Android; in each case Artemis's local data is deleted. Material policy changes receive a new version and require consent again.
