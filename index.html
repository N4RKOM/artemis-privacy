Политика конфиденциальности

Как мобильное приложение Artemis обрабатывает данные при работе с учебным порталом.

Редакция: 2026-09-10.1 Действует с: 10 сентября 2026 года
Artemis — независимое неофициальное приложение. Оно не является продуктом университета, оператора учебного портала или разработчиков Platonus и не представляет их интересы.

1. Кто отвечает за приложение

Разработчик и издатель Artemis — N4R. По вопросам конфиденциальности: n4r.artemis@gmail.com.

2. Какие данные обрабатываются

  • Данные для входа: логин и пароль, введённые пользователем.
  • Данные профиля и учебные данные: идентификатор и имя пользователя, расписание, оценки, задания, экзамены, посещаемость, учебные материалы, объявления, сообщения и другие сведения, доступные учётной записи на портале.
  • Данные сессии: токены, cookies и другие идентификаторы, необходимые для поддержания входа.
  • Локальные настройки: язык, тема, параметры уведомлений, подтверждение согласия, ПИН-код в виде криптографического проверочного значения и выбранные пользователем настройки защиты.
  • Файлы: материалы, которые пользователь самостоятельно загружает или открывает из учебного портала.

3. Как и зачем используются данные

Данные используются только для авторизации в учебном портале, загрузки и показа доступной пользователю учебной информации, офлайн-работы, напоминаний, защиты доступа к приложению и выполнения действий, явно выбранных пользователем.

Логин и пароль передаются по HTTPS непосредственно поддерживаемому учебному порталу на домене edu.aues.kz. У N4R нет собственного сервера, который получает логин, пароль, токены или учебные данные.

4. Хранение на устройстве

Токены сессии и добровольно сохранённый пароль хранятся в защищённом системном хранилище Android. Пароль сохраняется только после отдельного выбора пользователя на экране входа. Часть учебных данных хранится локально для офлайн-доступа. Биометрические шаблоны приложению не передаются — проверку выполняет Android.

5. Разрешения

  • Камера используется для сканирования QR-кода посещаемости. Кадры обрабатываются на устройстве и не сохраняются Artemis.
  • Уведомления используются для выбранных пользователем локальных напоминаний.
  • Биометрия используется только для подтверждения личности средствами Android, если пользователь включил эту возможность.

6. Передача третьим сторонам

Необходимые данные передаются оператору учебного портала для выполнения запрошенных функций. Artemis не продаёт данные, не показывает рекламу и не содержит сервисов аналитики или удалённого сбора сбоев. При открытии или отправке файла выбранное внешнее приложение обрабатывает его по собственным правилам.

Эта страница размещена на GitHub Pages. GitHub может обрабатывать технические данные посещения, включая IP-адрес, в соответствии со своей политикой конфиденциальности.

7. Срок хранения и удаление

При выходе Artemis удаляет активные токены, cookies, локальный учебный кэш, данные внутренней базы, виджета и запланированных напоминаний текущего профиля. Метаданные сохранённого профиля, подтверждение согласия, ПИН-код и пароль, сохранённый по выбору пользователя, могут оставаться для быстрого повторного входа до удаления сохранённого профиля или данных приложения.

Загруженные пользователем файлы могут оставаться на устройстве, пока пользователь не удалит их самостоятельно или не очистит данные приложения. Удалить все локальные данные также можно средствами Android или удалив приложение. Данные на учебном портале хранятся и удаляются его оператором; N4R не имеет доступа для их удаления.

8. Безопасность, согласие и изменения

Сетевые запросы выполняются только по HTTPS; незашифрованный HTTP в Android запрещён. Чувствительные данные помещаются в защищённое системное хранилище, а доступ к приложению можно дополнительно закрыть ПИН-кодом и биометрией.

Пользователь подтверждает согласие в приложении и может отказаться, выйти из профиля, удалить сохранённый профиль или очистить данные приложения. Существенные изменения политики получают новую версию и требуют повторного согласия. Вопросы и запросы можно направить на n4r.artemis@gmail.com.

English version

1. Who is responsible for the app

Artemis is developed and published by N4R. Privacy contact: n4r.artemis@gmail.com.

2. Data processed

  • The username and password entered by the user.
  • Profile ID and name, schedule, grades, assignments, exams, attendance, learning materials, announcements, messages, and other data available to the portal account.
  • Session tokens, cookies, local preferences, consent records, a cryptographic PIN verifier, and files downloaded by the user.

3. Purpose and transmission

Data is used only to sign in to the education portal, display academic information, provide offline access and reminders, secure the app, and carry out actions chosen by the user. The username and password are sent over HTTPS directly to the supported education portal at edu.aues.kz. N4R has no server that receives credentials, tokens, or academic data.

4. On-device storage

Session tokens and, only when separately selected by the user, the password are stored in Android protected storage. Some academic data is cached locally for offline access. Biometric templates are never provided to Artemis; authentication is performed by Android.

5. Permissions

  • The camera scans attendance QR codes on the device; Artemis does not retain camera frames.
  • Notifications provide local reminders selected by the user.
  • Biometrics only confirms identity through Android when enabled by the user.

6. Third parties

Required data is transferred to the education portal operator to provide requested functions. Artemis does not sell data, display advertising, or include analytics or remote crash-reporting services. A file opened or shared with another app is processed under that app's terms.

This page is hosted by GitHub Pages. GitHub may process technical visit data, including IP addresses, under its privacy statement.

7. Retention and deletion

Signing out removes active tokens, cookies, the current profile's offline academic cache, internal database data, widget data, and scheduled reminders. Saved-profile metadata, consent, PIN, and a password the user chose to save may remain for quick sign-in until the saved profile or app data is removed. User-downloaded files may remain until deleted by the user. Data held by the education portal is controlled by its operator.

8. Security and consent

Network requests use HTTPS and sensitive values are placed in protected system storage. The user provides consent in the app and can withdraw by signing out, removing a saved profile, or clearing app data in Android. Material policy changes receive a new version and require consent again.
